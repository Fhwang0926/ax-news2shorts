# 동물 행동 해설·권리 가드레일

TikTok Creative Center와 공개 페이지는 동물 영상을 발견하는 표면일 뿐 재사용 허가가 아닙니다. 원본 URL, 제작자, 수집 경로, 권리 상태를 보존하고 `unknown`을 임의로 바꾸지 않습니다.

## 동물 행동과 감정 표기

- 영상에서 보이는 자세, 이동, 시선, 꼬리·귀·털 상태, 발성, 상호작용만 `관찰`로 쓸 수 있습니다.
- 보호자·구조자·수의사가 원본에서 직접 말한 내용은 출처와 함께 `보호자 설명`으로 표시합니다.
- 감정, 의도, 통증, 과거 경험, 질병은 영상만으로 확정할 수 없습니다. 행동으로부터 해석할 때는 `행동 해석`을 붙이고 `가능성`, `보이는 모습`, `해석`처럼 제한해 씁니다.
- 댓글, 자동 번역, 배경음은 동물의 감정 근거가 아닙니다.
- 학대, 구조, 질병, 치료, 사망, 실종, 보호소, 미성년자 관련 장면은 `welfare_risk` 또는 `sensitive_topic`으로 기록하고 독립적인 출처를 확인합니다. 자극적 재편집이나 고통 장면 반복을 피합니다.

프로젝트 내부의 감정 기록은 항상 다음의 세 요소를 남깁니다. 렌더 화면에는 이 분석 용어와 근거 줄을 표시하지 않습니다.

1. 신뢰 구분: `관찰`, `보호자 설명`, `행동 해석`
2. 짧은 해석: 예: `낯선 공간을 경계하는 모습`
3. 실제 행동 근거: 예: `꼬리를 낮춘 채 보호자를 바라봄`

## 코믹 상황 비유

- 화면 자막은 실제 동작을 직장, 친구, 가족, 단체 대화방처럼 익숙한 사람 상황에 빗댈 수 있습니다.
- 상단에는 검증된 원본 채널 이름만 일반 텍스트로 고정합니다. `원본 채널` 배지나 알약 모양은 넣지 않고, 역할명·상황·1인칭 하소연·속마음·받아치기는 모두 하단에 씁니다.
- 여러 동물이 등장하면 실제 위치와 반복 행동을 기준으로 역할표를 먼저 정합니다. 장면 중간에 화자, 직급, 관계를 바꾸지 않습니다.
- 한 장면에는 한 번의 웃음 포인트만 두고 마지막 실제 결과까지 점층적으로 연결합니다.
- 외국어 내장 자막은 검토한 자막 사각 영역만 블러합니다. 반복되는 원문은 첫 큰 하단 자막에서 핵심 뜻과 상황극 훅을 함께 전달하고, 이후에는 실제 동작에 맞는 상황극만 이어 갑니다. 원문과 무관한 한국어 훅이나 별도의 작은 직역 줄을 동시에 쌓지 않습니다.
- 블러 영역은 워터마크·채널 정보와 분리하고, 자막 배치상 가능한 범위에서 동물 얼굴을 제외합니다. 대표 프레임과 장면 경계를 검토해 원문이 읽히지 않고 워터마크와 핵심 행동이 남는지 확인합니다. 전체 화면 블러·인페인팅·출처 제거는 하지 않습니다.
- 자막은 비유이며 동물이 실제로 해당 직업, 관계, 의도나 감정을 가진다는 주장으로 쓰지 않습니다.
- 학대, 질병, 구조, 공포처럼 민감한 장면에는 코믹 의인화를 적용하지 않습니다.

## 음악

배경음은 렌더러가 새로 만든 무보컬 음악 또는 공식 출처와 재사용 라이선스가 검증된 로컬 무보컬 음원을 사용합니다. 생성 음악에서 장면의 `music_mood`는 다음 중 하나입니다.

| 프로필 | 적합한 흐름 |
| --- | --- |
| gentle | 휴식, 차분한 관찰 |
| tender | 애착, 돌봄, 이별, 조심스러운 공감 |
| tension | 경계, 불안 가능성, 구조 전후의 긴장 |
| relief | 안전 확인, 회복, 재회, 안도 |
| playful | 호기심, 놀이, 활기, 가벼운 사람 상황 비유 |

자동 생성 모드에서는 장면의 `music_mood`에 맞는 배경음 구간을 이어 붙입니다. `music-plan.profile_id`를 직접 정하면 전체 영상은 그 하나의 프로필로 고정됩니다. 라이선스 음원을 선택하면 공식 원본 페이지, 제작자, 라이선스 URL, 필수 출처 문구, 로컬 파일 SHA-256을 기록하고 전달 문서와 게시 메타데이터에 출처를 포함합니다. 음악은 감정 주장을 강화하는 증거가 아니며, 영상의 행동 근거보다 앞서면 안 됩니다. 보컬·TTS·출처 불명 음원은 사용하지 않습니다. ‘무료’, ‘유명함’, ‘로열티 프리’만으로는 저작권이 없다고 표현하지 않습니다.

## 원본과 권리

상태는 다음대로 기록합니다.

- `owned`: 제작자가 원본을 소유한다.
- `licensed`: 기록된 라이선스가 계획된 사용을 포괄한다.
- `permission_confirmed`: 권리자가 기록된 허가를 주었다.
- `unknown`: 신뢰할 수 있는 권리 결론이 없다.
- `review_required`: 추후 검토가 필요하다.
- `not_permitted`: 다운로드와 렌더에 사용하지 않는다.

로컬 전용 흐름은 `not_permitted`가 아닌 공개 URL을 로그인·쿠키·우회 없이 내려받을 수 있습니다. 성공적인 다운로드는 로컬 확보 사실만 뜻하며, 재사용·게시·수익화 권리를 만들지 않습니다.

원본 워터마크와 출처는 지우지 말고, 실제 동물의 행동이나 사람의 발언을 바꾸지 마세요. 외국어 내장 자막 블러는 검토한 자막 영역에만 적용하고 원문·번역 연결을 프로젝트에 남깁니다. 원본 전체 재업로드 대신 짧은 자료 화면과 독립적인 한국어 해설을 사용합니다. 플러그인은 로컬 파일만 만들고 업로드 여부나 게시 적법성을 판단하지 않습니다.
