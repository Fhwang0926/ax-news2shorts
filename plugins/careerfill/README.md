# CareerFill

CareerFill은 지정한 로컬 경력 자료와 Notion 근거를 정리하고, 현재 Chrome 지원서 탭을 분석해 초안을 만들거나 승인된 필드를 직접 입력·검증하는 Codex 플러그인입니다.

## v0.4 범위

- PDF, DOCX, HWPX, Markdown, TXT, YAML 텍스트 추출
- 선택한 PDF 페이지를 로컬 PNG로 렌더링하고 JPG/PNG를 로컬 시각 검토 대상으로 준비
- 시각 관찰을 페이지·원본 해시와 연결하고 자동 승인되지 않은 Claim 후보로 기록
- 정확한 Notion 링크를 블록 단위 로컬 읽기 전용 스냅샷으로 등록·갱신
- Notion 링크·페이지 ID·블록 ID·스냅샷 해시가 연결된 Claim 후보 생성
- 등록된 Notion 블록과 Claim 검색
- 원문 파일·페이지·문단·섹션이 연결된 Claim 후보 생성
- 구조화된 프로필 충돌 탐지
- S1/S2 민감도 상한에 따른 파일명·본문 기반 Evidence 후보 검색(S3 제외)
- 현재 Chrome 탭의 DOM과 화면 캡처를 교차검증한 읽기 전용 지원서 분석 기록
- 화면상 필수 표시, 글자 수 카운터, 비활성 상태, 오류·경고, 진행 단계, 업로드 상태 관찰
- 검증된 Claim과 글자/UTF-8 바이트 제한을 연결한 답변 초안 검토
- `입력해줘`, `채워줘`, `직접 입력` 요청 시 정확한 현재 탭에 승인된 필드 입력
- Chrome 입력 연결 실패 시 동일 탭의 macOS 화면 제어로 전환
- 입력 후 필드값·선택값·바이트 카운터 재검증

다음 작업은 수행하지 않습니다.

- CareerVault 원본 파일 수정
- Notion 페이지·데이터베이스 수정 또는 새 페이지 생성
- Notion 토큰·쿠키·인증 정보 저장
- 데이터베이스 생성·초기화·재설정
- 파일 첨부
- 개인정보 동의·사실 확인·법적 서약 체크
- 작성완료, 저장, 다음 단계, 로그인, CAPTCHA 처리, 최종 제출

## 사용 순서

1. 새 Codex 작업에서 `$careerfill-setup`과 CareerVault 절대 경로 또는 정확한 Notion 링크를 전달합니다. 둘을 함께 사용할 수도 있습니다.
2. Notion 링크는 연결된 Notion 플러그인으로 정확한 페이지만 읽고, 사용할 수 없으면 사용자가 공유한 Chrome Notion 탭을 읽습니다.
3. 필요한 PDF 페이지·JPG·PNG의 로컬 시각 검토 결과와 로컬·Notion Claim을 확인하고, 실제 근거가 확인된 Claim만 승인합니다.
4. 지원서 탭을 Chrome에서 열고 `$careerfill-apply`로 분석하거나 `현재 탭에 입력해줘`라고 요청합니다.
5. 직접 입력 시 필요한 보안 확인을 한 번만 수행하고, 입력 후 화면 값을 다시 읽어 검증합니다.
6. 작성완료·저장·다음 단계·첨부·동의·제출은 별도로 요청하지 않으면 수행하지 않습니다.

`90_private` 폴더와 심볼릭 링크는 기본 제외됩니다. PDF 텍스트 추출과 페이지 렌더링은 로컬 환경에 PyMuPDF가 있을 때 사용할 수 있습니다. DOCX/HWPX는 텍스트·구조 분석만 하며 별도 오피스 변환기를 설치하지 않습니다. 이미지의 문자를 외부 OCR 서비스로 보내지 않습니다.

## Notion 링크 사용

```text
$careerfill-setup 이 Notion 경력 페이지를 읽기 전용 근거로 등록해줘: https://www.notion.so/...
```

- `notion.so`, `notion.site`, `notion.com`의 HTTPS 링크만 허용합니다.
- 링크 하나의 현재 페이지 블록만 읽으며 연결된 하위 페이지·첨부 파일·워크스페이스 전체를 자동 탐색하지 않습니다.
- 같은 링크를 다시 등록하면 로컬 스냅샷을 갱신합니다. 내용 해시가 달라진 Claim은 다시 `review_required`가 됩니다.
- 연결된 Notion 플러그인이 우선이며 Chrome은 읽기 전용 대체 경로입니다.

## 지원서 직접 입력

```text
$careerfill-apply 현재 고용24 지원서에 검증된 경력을 직접 입력해줘. 저장과 제출은 하지 마.
```

- 현재 탭과 필드값이 확정된 경우 불필요한 설명이나 반복 확인 없이 입력합니다.
- 브라우저 또는 화면 제어 정책상 확인이 필요한 경우 목적지와 입력값을 한 문장으로 한 번만 확인합니다.
- 사용자가 해당 실행의 정확한 사실을 확인하면 전역 Claim 상태를 바꾸지 않고 그 실행에만 사용할 수 있습니다.
- 임금, 병역, 장애·보훈, 법적 동의 등은 자동 추정하거나 입력하지 않습니다.
- 입력 후 화면의 실제 값과 글자·바이트 카운터를 다시 확인합니다.
