# Editorial and rights policy

## 기사형

- 뉴스픽은 후보 발견과 링크 확인에만 사용합니다. 원 언론사·공식 기관·독립 출처를 열어 사실을 확인합니다.
- 기사 문장, 제목, 사진, 동영상을 그대로 복사하거나 낭독하지 않습니다. 확인된 사실을 claim ID로 기록하고 표현·순서·해설을 새로 구성합니다.
- 일반 생활 기사는 원 출처 또는 공식 자료 하나와 독립 출처 하나 이상을 사용합니다.
- 범죄, 사망, 미성년자, 의료, 자해, 심각한 가족 분쟁은 민감 주제로 기록하고 피해자·가족의 사생활과 존엄을 우선합니다.

## 익명 사연형

- 직접 제보는 제공자의 게시 동의 범위를 기록합니다.
- 공개 게시물은 공개 상태가 재게시·각색 허가를 뜻하지 않습니다. 고유 표현을 복사하지 않고 비식별화·재구성합니다.
- 이름, 상세 지역, 직장·학교, 정확한 날짜, 고유 가족관계와 계정명 등 식별 요소를 제거하고 제거 항목을 기록합니다.
- 사실 검증이 불가능하면 `사연을 바탕으로 재구성` 표시를 `publish.json`과 업로드 설명에 넣습니다.

## 음식 영상

- 로컬 파일이 존재해도 사용 허가를 자동으로 추정하지 않습니다.
- 원본 URL, 제작자, 수집 시각, 로컬 SHA-256, 워터마크 상태, 권리 상태를 보존합니다.
- 도우인 자동 다운로드, 로그인·쿠키·CAPTCHA·지역 제한·DRM 우회, 워터마크 제거·블러·가림을 하지 않습니다.
- 자동 원본 가져오기는 제작자·라이선스 제공처가 직접 준 HTTPS 영상 URL만 사용합니다. `owned`, `licensed`, `permission_confirmed` 상태와 사용자의 다운로드·편집 권리 확인이 필요하며 도우인 페이지·CDN과 사설 네트워크 주소는 거부합니다.
- 화면 중국어가 없는 후보와 구간을 우선합니다. 중국어가 보이는 원본은 문자를 지우거나 가리는 대신 해당 구간을 제외하고, 워터마크·출처 표시는 그대로 보존합니다.
- `negotiation_pending`은 추가 검토 워터마크가 없는 로컬 검토본만 허용합니다.
- 최종본에는 `owned`, `licensed`, `permission_confirmed`와 상업 이용·YouTube·편집·음성 오버레이 범위가 확인된 증빙이 필요합니다.

후보 조사, 파일 취득, 정적 검증, 로컬 렌더, 권리 검토, 게시 가능 상태를 별도로 보고합니다. 하나의 성공이 다른 성공을 대신하지 않습니다.
