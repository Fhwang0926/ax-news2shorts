# Scene image style

Use the same visual language for every scene:

- `1080x1920` vertical canvas;
- warm beige paper background near `#F5EBD7`;
- dark-gray pencil or ink lines;
- red, orange, or blue only as restrained accents;
- simple subjects, separated objects, clean background, and generous whitespace;
- no words, letters, numbers, labels, logos, photorealism, 3D effects, or dense textures.

Keep important subjects outside the top and bottom title-safe areas. Avoid overlapping unrelated objects because the renderer exposes rectangular semantic regions in sequence.

If a source image contains text or visually merged objects, stop and revise the image before annotation instead of compensating with inaccurate regions.
