# Shorts Studio 로맨스 검토본 제작 대기

## 진행 완료

- 기존에 승인된 「진짜 사랑과 가짜 사랑이 갈릴 때 나타나는 신호 3가지」 대본·스토리보드·캐릭터 장면을 로맨스 전용 입력으로 정리했다.
- 지우와 서준의 기존 Typecast 대사 7개를 장면 타이밍에 맞춘 27.7초 로컬 음성 트랙으로 구성했다.
- `projects/shorts-studio/2026-08-27/true-love-signals-romance` 프로젝트를 초기화했다.
- 기존 캐스트·장면 승인 기록을 근거로 `assets` 단계를 승인했다.

## 현재 상태

- 프로젝트 상태: `assets_reviewed`
- 자산: 합성 장면 이미지 7개, 지우·서준 Typecast 음성 트랙
- 프로젝트·장면 권리: `review_required`
- 합성 콘텐츠 표시 검토: 미승인
- 게시 승인: 미승인

## 다음 단계

1. 사용자가 합성 장면임을 표시하는 조건을 검토하고 승인한다.
2. `content` 단계를 승인한다.
3. Typecast 음성이 포함된 로컬 검토본을 렌더한다.
4. 검토본 확인 후 권리와 게시 승인을 별도로 진행한다.

권리와 게시 승인이 끝나기 전에는 최종본·업로드 패키지·YouTube 업로드를 진행하지 않는다.
