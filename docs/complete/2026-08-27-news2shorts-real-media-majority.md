# news2shorts 실사 중심 장면 규칙 및 재렌더 완료

## 작업 범위

- `news2shorts` 새 프로젝트 버전을 14로 올리고 실제 사진·영상 장면 비율 기본값을 60%로 추가했다.
- 권리 매니페스트의 `media_type`을 기준으로 사진·영상과 도표·문서·픽토그램을 구분한다.
- 승인·비합성·기사 연관성 검토를 모두 통과한 `photo` 또는 `video`만 실사 비율에 포함한다.
- 실사 비율이 기준보다 낮으면 검토본에서 경고하고 최종본에서 차단한다.
- 기존 version 13 이하 프로젝트의 검증 동작은 유지했다.

## 프로젝트 반영

- 대상: `projects/2026-08-27-interest-rate-again`
- 기존 자체 그래픽 5개 장면을 권리 확인된 Wikimedia Commons·Pexels 실사로 교체했다.
- 뉴스 장면 6개 중 6개가 `media_type: photo`로 기록되어 실사 비율은 100%다.
- 한국은행 전경, 주택담보대출 서류 상담, 주택 열쇠·계산기, 가계 재무 계산, 대출 약정 상담 장면을 사용했다.
- 정확한 금리·기간·추산 조건은 사진 안에 합성하지 않고 렌더러 자막으로 유지했다.
- 사람 자료사진에는 실제 보도 당사자가 아니라는 기록과 화면 크레딧을 남겼다.
