# news2shorts 필재·다은 자동 음성 분포 반영

## 완료 일자

- 2026-08-21

## 반영 범위

- 일반 자동 프로젝트는 Typecast 필재를 80%, 다은을 20% 비중으로 선택한다.
- 같은 프로젝트를 다시 렌더할 때 목소리가 우연히 바뀌지 않도록 프로젝트 식별값을 이용한 고정 10개 버킷을 사용한다.
  - 버킷 0-7: 필재
  - 버킷 8-9: 다은
- 다음 전용 보이스 규칙은 유지한다.
  - 민감 뉴스: 서현
  - 내레이션 장면 절반 이상이 사용법·대처·절차인 경우: 문정
  - 55초 이상 스토리 설명: 강일
- 사용자가 보이스를 직접 지정한 경우 수동 설정을 가장 먼저 적용한다.
- 분포와 버킷 근거를 프로젝트와 렌더 보고서에 기록한다.
- 자동 선택이 불가능한 호환 대체 보이스도 다은에서 필재로 변경한다.

## 변경 파일

- `plugins/news2shorts/scripts/news2shorts.py`
  - 프로젝트 고정 SHA-256 버킷 선택과 필재 80%·다은 20% 분포를 추가했다.
  - 진단, 프로젝트, 렌더 보고서에 분포 근거와 버킷을 기록한다.
  - 기본 대체 보이스를 필재로 변경했다.
- `plugins/news2shorts/skills/news2shorts/SKILL.md`
  - 자동 선택 및 예외 규칙을 새 정책과 일치시켰다.
- `plugins/news2shorts/skills/news2shorts/references/output-contract.md`
  - 프로젝트 및 렌더 보고서의 음성 분포 필드를 문서화했다.
- `plugins/news2shorts/README.md`, `README.md`
  - 사용자용 기능 설명을 새 기본값과 일치시켰다.
- `plugins/news2shorts/.codex-plugin/plugin.json`
  - 플러그인 버전을 `0.21.0+codex.20260821`로 올렸다.

## 설계 판단

- 진짜 난수를 매 렌더마다 다시 뽑으면 검수 중 목소리가 바뀌므로 사용하지 않았다.
- 80:20은 Typecast 사용량 순위가 아니라 플러그인 제작 정책이다.
- 외부 패키지나 새 저장소 없이 Python 표준 라이브러리만 사용했다.
