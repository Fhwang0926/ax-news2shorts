# 빅뱅 드림캡슐 쇼츠 재미 강화판 제작 완료

## 수정 이유

- 최초 영상은 첫 장면에서 정답을 먼저 공개해 이후 장면의 반전이 약했다.
- 인물을 피하기 위해 사용한 추상 조형물이 직관적인 상황과 유머를 전달하지 못했다.
- 설명형 문장이 길고 장면별 역할이 비슷해 뉴스 카드가 연속되는 인상이 강했다.

## 강화 내용

- 첫 장면을 `빅뱅, 진짜 우주로 갑니다`로 열고 2.3초 뒤 빈 우주복 장면에서 `멤버는 안 갑니다`로 즉시 뒤집었다.
- 5장면을 6장면으로 재구성하고, 오해, 정정, 실제 미션, 메시지 변환, 발사 계획, 탑승객 공개로 각 장면의 역할을 분리했다.
- 익명 세 사람의 로켓 행진, 빈 우주복 세 벌, 관제 콘솔에 꽂힌 마이크, 메시지 스캐너, 준비 중인 발사체, 안전벨트를 맨 메시지 봉투를 새로 생성했다.
- 실제 빅뱅 멤버의 얼굴, 그룹 로고, 보도 사진, 방송 화면, 음원은 사용하지 않았다.
- 내레이션 속도를 높이고 마지막 문장을 `진짜 탑승객은, 팬들의 메시지였습니다`로 줄여 보상 직후 끝나도록 했다.

## 사실·권리 처리

- 위촉과 드림캡슐 참여는 SBS와 뉴시스, 발사 목표 시점은 우주항공청과 Korea.net 자료를 그대로 유지했다.
- `누리호 5차에 실을 계획`, `2026년 3분기 목표`, `계획 단계`로 표시해 완료된 발사로 오인하지 않게 했다.
- 모든 장면 이미지는 프로젝트용 생성 자산이며 화면에 `AI 생성 이미지` 또는 `AI 재현 이미지`를 표시했다.
- 로컬 시스템 음성은 검토본 제작에만 사용했으며 외부 게시나 유튜브 업로드는 수행하지 않았다.

- 프로젝트 일반 검증과 최종 규칙 검증 모두 오류 및 경고 없이 통과
