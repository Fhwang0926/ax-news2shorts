# News2Shorts 한국어 TTS 숫자 읽기 프롬프트 개선

## 반영 내용

- 화면 문구는 `5조각 · 2조각`처럼 짧은 숫자 표기를 유지한다.
- Typecast에 전달하는 `narration`은 `다섯 개`, `두 개`처럼 자연스러운 한국어 수사와 단위로 작성한다.
- `5조각`을 `오 조각`으로 기계적으로 읽지 않도록 금지 예시를 명시했다.
- 사람·사건·장소 수량도 문맥에 맞춰 `한 명`, `세 건`, `네 곳`으로 쓰도록 했다.
- 날짜·가격·비율·모델명·법률 식별자 등 정확성이 중요한 값은 의미를 바꾸지 않으며, 같은 사실을 보존하면서 발음이 좋아지는 경우에만 한글 독음을 사용한다.
- Typecast 전달 전에 숫자와 단위가 붙은 모든 표현을 훑어 기계적이거나 모호한 발음을 수정하도록 했다.

## 범위

- 사용자 요청대로 프롬프트 지침과 플러그인 버전만 변경했다.
- 렌더러, 검증 코드, 기존 프로젝트 대본과 영상은 수정하지 않았다.
- 새 TTS 생성이나 영상 재렌더는 수행하지 않았다.
