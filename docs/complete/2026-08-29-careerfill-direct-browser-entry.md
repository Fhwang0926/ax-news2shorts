# CareerFill v0.4 직접 브라우저 입력

## 목적

사용자가 현재 지원서에 `입력해줘`, `채워줘`, `직접 입력`이라고 명시하면 CareerFill이 근거와 폼 제한을 확인한 뒤 승인된 필드를 실제 브라우저에 입력하고 재검증하도록 확장했다.

## 반영 내용

- `careerfill-apply`에 분석/초안 모드와 직접 입력 모드 분리
- 정확한 현재 Chrome 탭과 필드별 입력 계획 확인
- Browser/Computer Use 정책상 필요한 확인은 목적지와 데이터를 한 문장으로 한 번만 요청
- 동일한 목적지·데이터에 대한 불필요한 반복 설명과 확인 금지
- Chrome 의미 기반 입력 우선
- Chrome Playwright·DOM·입력·클립보드 연결 실패 시 같은 Chrome 탭의 Computer Use로 전환
- 텍스트 필드, 선택창, 직종 검색 결과, 글자·바이트 제한 직접 입력·선택
- 입력 후 모든 값과 카운터 재확인
- 전역 Claim이 검토 중이어도 사용자가 정확한 필드 사실을 확인한 경우 해당 실행에서만 사용

## 고용24 적용 증거

- 회사명: F1security
- 재직기간: 2018-02 ~ 2026-07
- 직급/직책: 개발팀 리더
- 재직 여부: 퇴직
- 직종: 정보보안 전문가
- 주요 직무: 300/500Byte
- 기타 사항: 267/500Byte
- 총 근무기간 자동 계산: 8년 6개월
- 임금: 공란
- 작성완료·저장·제출: 수행하지 않음

## 중단선

- 임금과 민감·법적 필드 자동 추정 금지
- 첨부·업로드 금지
- 개인정보 동의·사실 확인·서약 자동 체크 금지
- 작성완료·저장·다음 단계·최종 제출은 별도 명시적 요청과 필요한 확인 전까지 금지
- CAPTCHA와 브라우저 보안 경고 우회 금지

## 검증 범위

- 고용24 화면 accessibility 값 재확인
- 플러그인 validator
- `careerfill-apply` skill validator
- JSON·YAML·Markdown 참조 경로 정적 검사
- 설치 캐시와 소스 동일성
- `git diff --check`

사용자 지시에 따라 빌드와 테스트 스위트는 실행하지 않는다.
