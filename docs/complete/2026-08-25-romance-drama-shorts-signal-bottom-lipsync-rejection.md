# 연애 드라마 Shorts 시그널 하단·립싱크 품질 반려 반영 완료

## 요청

- `신호 1~3` 카드를 중앙 영상창 하단에 표시한다.
- 부자연스러운 립싱크를 개선한다.

## 반영 내용

- 시그널 카드의 아래쪽을 중앙 640×800 영상창의 하단에서 30px 안쪽에 고정했다. 세 단계 팝업 크기가 달라져도 아래 기준선은 유지된다.
- v9의 두 입 포즈·음성 세기 기반 입 모션은 사용자 품질 검토에서 반려된 것으로 기록하고 v10 `sync-plan.json`에서 모두 분리했다.
- 반려된 입 포즈와 MP4는 제작 이력과 출처 확인을 위해 삭제하지 않고 `used_in_latest_output: false`로 보존했다.
- 플러그인에서 두 포즈 립싱크 생성 명령과 구현을 제거했다.
- 향후 립싱크는 게시 가능한 권리 상태와 `review_status: approved`가 함께 기록된 프로젝트 로컬 영상만 합성한다.
- 검토된 립싱크가 없으면 Typecast 음성, 발화 구간 자막, 화면 비트, 생성 BGM을 유지하고 일반 시네마틱 이미지 모션으로 렌더한다.

## 변경 파일

- `plugins/romance-drama-shorts/scripts/romance_drama_shorts.py`: 시그널 하단 기준 배치, 두 포즈 립싱크 생성 코드 제거, 립싱크 품질 승인 게이트 추가, 버전 `0.1.8`.
- `plugins/romance-drama-shorts/skills/romance-video-producer/SKILL.md`: 시그널 하단 규칙과 검수되지 않은 립싱크 금지 기준.
- `plugins/romance-drama-shorts/README.md`: 제거된 명령과 품질 기준 반영.
- `plugins/romance-drama-shorts/.codex-plugin/plugin.json`: `0.1.8+codex.20260825221206` 버전 갱신.
- 프로젝트 `sync-plan.json`, `lip-sync-pilot.json`, `project.json`, `rights-manifest.json`: v10 출력, 반려 상태, 최신본 미사용 기록.
- 프로젝트 `outputs/preview-boxed-signal-bottom-v10.mp4`, `boxed-signal-bottom-v10-report.json`: 새 검토본과 검수 결과.

## 검증

- 대표 프레임 0.2초, 1.2초, 6.7초, 14.8초, 23.0초, 28.6초를 직접 확인했다.
- 시그널 1·2·3은 모두 영상창 하단 안쪽에 표시되며 제목, 얼굴, 하단 바깥 여백과 겹치지 않는다.
- 최신 보고서의 립싱크 적용 숏은 0개다.
- H.264/AAC, 720×1280, 30fps, 29.521초, 48kHz 스테레오로 확인했다.
- 전체 영상 디코딩과 검은 프레임 검사를 통과했다.
- 프로젝트 검증은 오류와 경고 없이 통과했다.

## 남은 경계

- 현재 v10은 부자연스러운 가짜 입 모션을 제거한 검토본이며, 음소 단위 실제 립싱크 결과는 아니다.
- 실제 립싱크는 영상 모델이 사용 가능한 제공자에서 만든 결과를 음소 타이밍, 인물 동일성, 치아·턱 안정성, 무음 구간 기준으로 별도 검수한 뒤 적용해야 한다.
- 권리, 합성 콘텐츠 표시, 게시 승인은 계속 미완료이며 결과물은 로컬 검토용이다.
- DB 작업과 프론트엔드 빌드는 수행하지 않았다.
