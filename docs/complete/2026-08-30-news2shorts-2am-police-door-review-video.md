# 새벽 2시 경찰 방문 안전 확인 쇼츠 검토본 완료

## 작업 범위

- 사용자 제공 Threads 영상에서 개인 이름이 보이지 않는 네 구간을 원본 음성 포함 상태로 분리했다.
- 모든 원영상 장면에 `Threads @newsletter_kr`와 원본 작성자 `@eunbin_file` 출처를 표시했다.
- 실제 경찰 여부를 단정하지 않고, 소속·성명·방문 목적 확인과 의심 신호를 중심으로 6장면 퀵리빌 대본을 작성했다.
- `신분 확인 회피`와 `문 열기 재촉`을 의심 신호로 명시했다.
- 개인정보 노출을 피하는 설명용 삽화 2장을 생성하고 별도 썸네일을 만들었다.
- 최초 로컬 검토본은 macOS Yuna로 생성했고, 사용자 승인 후 Typecast `Seohyeon`으로 교체했다.
- 후속 검토에서 원본 장면 1·3·4·5는 실제 대화를 주 음성으로 복원하고, 장면 2·6·CTA만 Typecast를 사용하도록 교차 배치했다.
- 초반 `내장 저장공간/DCIM/Camera` 경로 표시는 원본 6.5초 이후 구간으로 교체해 제거했다.
- 원본 영상 장면의 뉴스한면 상단 제목·하단 자막을 제거하고, 원본 하드코딩 대화 자막과 작은 출처 표기만 유지했다.
- 외부 SRT는 Typecast 장면 2·6과 CTA의 3개 큐만 남겨 원본 자막과 중복되지 않게 했다.
- 마지막 Typecast 문장을 `지구대에서 왔다고 해도 문을 열기 전 신분과 방문 목적을 확인하세요. 안 되면 112에 확인하세요.`로 다시 합성했다.

## 검증

- 720×1280, H.264/AAC, 29.047초, 영상·음성 스트림 확인
- Typecast `ssfm-v30`, `Seohyeon`은 설명 장면 2·6과 CTA에 유지
- 원본 대화는 장면 1·3·4·5에 Typecast 중첩 없이 배치
- 첫 Typecast 사실 제한 노출: 2.500초
- 마지막 Typecast 안내 5.902초, CTA 2.000초
- 장면 전환 검은 프레임과 0.8초 이상 무음 구간 미검출
- SRT 3개 큐 순서 정상, 마지막 큐 29.342초로 영상 범위 내 확인
- 원본 음성 평균 음량 약 -18~-21dB, Typecast 약 -16~-18dB로 확인
- 0.57초 암부 검출 구간은 장면 전환이 아닌 원본 현관의 실제 어두운 화면이며 원본 자막이 계속 표시돼 유지
- 개인 이름이 대본·자막·출처 기록에 포함되지 않음을 확인
- 로컬 검증 오류 0건
- 플러그인 `audio_mode: source-video` 경로로 다시 렌더해 장면 1 영상·음성 시작점이 모두 0.000초임을 확인

## 남은 제한

- 제공 영상은 사용 지시만 받았고 권리 보유 또는 재사용 허락 증빙은 확인되지 않았다.
- 플러그인의 실사진 요건을 충족하는 권리 승인 사진이 없다.
- 따라서 현재 결과는 `preview.mp4` 로컬 검토본이며 게시용 `short.mp4`는 생성하지 않았다.
- 게시용 최종본에는 영상 권리 증빙, 실사진 요건, 편집 검토, 게시용 음성 검토가 추가로 필요하다.

## 코드 영향

- 플러그인 소스 코드와 기존 프로젝트는 수정하지 않았다.
- 새 프로젝트 및 당일 완료 기록만 추가했다.
- 프론트엔드 빌드나 데이터베이스 작업은 수행하지 않았다.
