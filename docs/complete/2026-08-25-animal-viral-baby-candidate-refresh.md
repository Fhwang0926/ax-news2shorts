# Animal Viral Shorts 아기 동물 후보 재조사

## 완료 일자

- 2026-08-25

## 요청 반영

- 기존 경기장 대형견 초안은 추가 제작하지 않고 보존했다.
- 단순 귀여움보다 반복 행동·상황 대조·주차별 변화가 있는 아기 동물 원본을 다시 조사했다.
- TikTok 공개 원작자 페이지와 공식 임베드 지표를 확인하고, 재생 가능한 후보는 구간별 장면까지 검토했다.

## 점수화 결과

- `@stephandjd`: 아기 토이푸들이 아침마다 침대를 향해 반복 도약하는 8.1초 원본.
- `@percy.boy.jackson`: 수건에 감싸인 아기 코커스패니얼과 빗물 맺힌 창문을 교차하는 원본.
- 위 두 후보가 자격 조건을 통과했고, 자동 선택 없이 사용자 선택 대기 상태로 생성됐다.
- `@willowthefurrball`의 16주차 성장 기록은 공개 지표와 대표 프레임만 확인되고 전체 결말을 재생 검증하지 못해 정식 후보에서 제외했다.

## 변경 파일

- `projects/2026-08-25-animal-viral-baby-candidates-v3/candidates.input.json`: 공개 지표, 실제 행동, 이야기 흐름, 활용 방향, 한계와 권리 상태를 기록했다.
- `projects/2026-08-25-animal-viral-baby-candidates-v3/candidates.ranked.json`: 플러그인 점수화 결과를 생성한다.

## 검토 경계

- 통과한 두 후보 모두 공개 원본 계정은 확인했지만 재사용·상업 이용 허가는 확인하지 못해 권리 상태를 `unknown`으로 유지했다.
- 후보 선택 전 원본 다운로드·영상 렌더·게시·상품 링크 생성은 수행하지 않았다.
- 원본에 등장하지 않는 펫 스텝·우비·타월·방석의 효능은 주장하지 않는다. 구매 연결은 별도 자체 촬영에서 크기·미끄럼·세탁성 같은 항목을 실제 확인해야 한다.
