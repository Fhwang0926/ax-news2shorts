# news2shorts 유지율 검증과 추석지원금 재렌더 완료

## 요청

- 기존 49.5초 팩트스택 영상의 긴 호흡과 재미 부족 원인을 플러그인에서 개선한다.
- 같은 뉴스와 팩트스택 형식을 유지해 더 짧은 Typecast 최종 영상을 다시 만든다.

## 플러그인 개선

- 30초 영상의 Typecast 대사를 공백 제외 170~190자 권장으로 명시했다.
- 대사 길이로 예상 렌더 시간을 계산하고 목표 대비 15% 초과는 초안 경고, 25% 초과는 최종 오류로 처리했다.
- 실제 Typecast 렌더 보고서의 장면 길이를 다시 검사해 일반 장면 4.5초 초과를 경고하고 6초 초과를 최종 오류로 처리했다.
- 결론 장면은 읽을 시간을 고려해 3.5~6초를 권장하고 7초 초과를 최종 오류로 처리했다.
- 생성 이미지 비중 70% 초과와 생성 이미지 4장면 이상 연속 사용을 경고하도록 했다.
- 숫자 비교·반전형 35초 이하 쇼츠는 Typecast `Daeun`, 일반 팩트스택은 `Seohyeon`, 절차 설명이 장면의 절반 이상인 경우만 `Moonjung`을 선택하도록 자동 라우팅을 조정했다.
- 렌더 보고서에 각 장면의 `beat`를 기록해 후크·근거·반전·결론별 시간을 검증할 수 있게 했다.
- 플러그인 버전을 `0.16.0+codex.20260819`로 올리고 현재 Codex 설치본을 갱신했다.

## 재렌더 결과

- 같은 뉴스의 핵심 사실과 `fact-stack` 형식을 유지했다.
- 7장면 49.5초에서 6장면 23.57초로 줄였다.
- 후크를 `추석지원금, 2만 원 대 5만 원.`으로 즉시 제시했다.
- 설명을 `정답은 지역 사업. 전국 공통이 아닙니다.`처럼 짧은 대화형 문장으로 연결했다.
- 실제 자료사진 2장과 설명용 픽토그램 4장을 교차 사용했다.
- 마지막 결론은 `주소지별 별도 사업 / 신청 방식까지 거주지 확인` 카드로 5.71초 노출했다.
- Typecast 자동 라우팅으로 `Daeun`(`tc_692799c46508f6b9468c54c7`)을 선택하고 tempo 1.1로 합성했다.
