# 2026-08-10 news2shorts MVP 작업 완료

## 작업 범위

- Codex 플러그인 기본 패키지와 `news2shorts` Skill을 추가했습니다.
- 뉴스 URL 모드와 오늘 뉴스 후보 모드의 편집 워크플로를 정의했습니다.
- NAVER API HUB 뉴스 검색과 후보 군집화 명령을 구현했습니다.
- 프로젝트 초기화, 검토용/최종 렌더, 프로젝트·영상 검증 명령을 구현했습니다.
- 출처, 팩트, 이미지 권리, 합성 콘텐츠 표시를 추적하는 출력 계약을 추가했습니다.
- Pillow, FFmpeg, macOS 기본 한국어 음성을 활용하는 1080x1920 렌더러를 추가했습니다.
- 사용자 승인 없는 외부 업로드, DB, 웹 UI, MCP 서버는 제외했습니다.

## 안전장치

- 일반 뉴스는 두 개, 민감 뉴스는 세 개의 독립 출처를 요구합니다.
- 최종 렌더는 편집·권리·합성 표시 검토가 완료되지 않으면 차단됩니다.
- 권리 기록이 없거나 승인되지 않은 이미지는 최종 렌더에서 차단됩니다.
- 생성 이미지가 사용되면 `publish.json`의 합성 콘텐츠 표시가 필요합니다.
- 프로젝트 밖의 이미지·오디오·출력 경로를 허용하지 않습니다.
- API 키는 환경 변수에서만 읽고 출력하지 않습니다.
