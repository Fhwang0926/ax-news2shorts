# 2026-08-31 news2shorts 네팔 터널 마지막 희망 검토 영상

## 작업 범위

- 사용자가 선택한 `1번` 후보를 `산소 투입 터널, 근로자 안전의 마지막 희망일까요?`라는 후속 주제로 확정했다.
- `생존률이 가장 높다`는 확인되지 않은 비교 표현은 제외하고, 지하 구조·산소 공급·높은 수위·무응답·직접 진입 조건만 사용했다.
- 한국인 아홉 명 수색 현장인 어퍼트리슐리 1과 영상 중심 현장인 어퍼트리슐리 3A를 초반에 구분했다.

## 변경 파일

- `projects/2026-08-31-nepal-tunnel-last-hope/project.json`: 민감 뉴스, 시민 안전 훅, 사실 제한, 국제 실제사건 시각 범위와 승인 상태를 기록했다.
- `sources.json`, `fact-sheet.json`: 네팔 정부 구조 포털, Radio Nepal, Kathmandu Post, Reuters, Khabarhub, 연합뉴스 근거와 여덟 개 검증 주장을 기록했다.
- `script.md`, `storyboard.json`: 여섯 장면을 실제 뉴스 사진 전용으로 구성하고, 잔해 속 진입점 수색 내용에 맞춰 3번 장면 내레이션을 수정했다.
- `rights-manifest.json`: 여섯 장면의 실제 기사 사진 출처·해시·기사 연관성·권리 검토 상태를 기록했다. 생성 도식은 이전 이력으로만 남기고 활성 스토리보드에서는 제외했다.
- `publish.json`: 질문형 제목, 링크 없는 설명, 태그, 고정 댓글과 비공개 업로드 설정을 완성했다.
- `assets/`, `preview.mp4`, `edit-package/preview/`: 실제 뉴스 사진 여섯 장, 로컬 음성 검토본과 CapCut/Vrew 호환 패키지를 생성했다. 기존 생성 썸네일은 비활성 보관 위치로 옮기고 활성 `thumbnail.jpg`는 두지 않았다.
- `outputs/media-qa.json`, `outputs/youtube-upload-info.md`: 화면·오디오 QA와 복사용 업로드 정보를 기록했다.

## 렌더 결과

- 검토본: 720×1280, 30fps, H.264/AAC, 25.239초.
- 영상 본문 장면은 6/6 모두 실제 뉴스 사진이며 생성 이미지·지도·도식은 사용하지 않았다. CTA와 브랜드 마감만 그래픽이다.
- 음성: 사용자가 Typecast 전송을 명시적으로 승인한 뒤 민감 뉴스 자동 보이스 `Seohyeon`, 모델 `ssfm-v30`으로 다시 생성했다.
- 첫 답변·사실 제한: 3.229초, 재후킹: 7.370초.
- 본문 50.88% 지점인 scene-03 뒤에 Typecast `Seohyeon` 중간 CTA 1.597초를 넣고, 마지막 구독 CTA는 0.8초 무음 브랜드 마감으로 유지했다.
- CTA 경계를 TTS 생성 전에 확정하고 앞 본문과 뒤 본문을 Typecast 두 요청으로 각각 생성했다. CTA는 완전한 두 발화 사이에만 들어가며 글자 수 비례 음성 조각을 자르지 않는다.
- CTA 앞뒤 결합 무음은 각각 0.128초와 0.263초로 측정됐고 활성 음성 절단은 확인되지 않았다.
- 업데이트한 렌더러가 `preview.mp4`와 동일한 `reference.mp4`를 직접 생성했으며 수동 재합성은 필요하지 않았다.
- 검은 화면 0구간, 내부 0.5초 이상 무음 0구간, 통합 음량 -13.9 LUFS, true peak -2.5 dBFS.
- 여섯 장면과 CTA·브랜드 마감의 접촉시트를 육안 검토했으며 텍스트 겹침과 위험한 잘림은 확인되지 않았다.

## 검증과 제한

- 초안 검증은 실제 뉴스 사진 여섯 장의 권리 경고를 유지한 채 오류 0건으로 통과했다.
- 최종 검증은 실제 뉴스 사진 여섯 장의 사용 권리 미승인, 권리 승인 실사 0/6, 편집·권리 승인 미완료로 차단했다.
- 영상과 별도로 필요한 공개용 썸네일도 실제 뉴스 사진만 사용하도록 설정했지만 권리 승인 사진 두 장 이상이 없어 생성 차단했다.
- `short.mp4` 최종 공개본과 YouTube 업로드·예약·고정 댓글 게시를 수행하지 않았다.
- 프론트엔드 빌드와 단위 테스트는 사용자 지침에 따라 실행하지 않았다.
