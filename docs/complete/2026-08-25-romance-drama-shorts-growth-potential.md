# 연애 드라마 Shorts 일일 변화·상승 가능성 반영

## 완료 내용

- 이전 날짜의 후보 파일을 오늘 수집 결과처럼 재사용하지 않도록 리서치 기본 계약을 강화했다.
- 실행마다 새 `browser-candidates.json`을 만들고, 직전 동일 범위 파일은 비교 기준으로만 사용하도록 했다.
- 동일 후보를 URL 또는 `content_fingerprint`로 연결해 `new`, `updated`, `unchanged`, `unverified`를 표시한다.
- 조회수·좋아요·댓글 변화량과 관측 간격으로 일별 반응 속도를 계산한다.
- 상승 가능성을 신선도 20, 반응 모멘텀 30, 현재 도달 15, 참여 밀도 15, 이야기 확장성 15, 국가 간 공감도 5로 계산한다.
- 공개 화면의 반올림 수치는 신뢰도를 높음으로 올리지 않는다. 오늘 반응을 확인하지 못한 후보는 전날 수치를 복사하지 않고 반응 속도 점수를 제외한다.
- 2026-08-25 공개 화면에서 확인한 후보만 별도 수집본으로 저장하고 2026-08-24 수집본과 비교했다.
- Codex 플러그인 `romance-drama-shorts@news2shorts-local`을 `0.1.3+codex.20260825190000`으로 설치했다.

## 오늘 비교 결과

- 미국: 4개 확인. 신규 2개, 반응 갱신 2개.
- 한국: 2개 확인. 반응 갱신 1개, 현재 반응 미확인 1개. 비공식 드라마 클립은 제외했다.
- 일본: 3개 확인. 신규 1개, 반응 갱신 1개, 현재 반응 미확인 1개.
- Instagram Reels는 세 국가 모두 비로그인 공개 경로에서 개별 게시물을 재검증하지 못해 `blocked`로 기록했다.
- 모든 제3자 후보 권리는 `review_required`이며 상승 점수와 재사용 허가는 별개다.

## 제한

- 상승 가능성은 공개 반응의 관측 기반 우선순위이며 미래 조회수 예측이나 보장이 아니다.
- 신규 후보는 비교 시점이 한 번뿐이므로 게시 경과일 대비 누적 반응을 대리 지표로 사용하고 신뢰도를 낮음으로 표시한다.
- K, 만 단위로 반올림된 공개 수치의 변화량은 근사값이다.

## 후속 선택

- 사용자가 오늘 비교 결과에서 `US-YT-05`를 직접 선택했다.
- 같은 Candidate ID로 이미 제작된 프로젝트가 있어 새 프로젝트를 중복 생성하지 않고 기존 프로젝트를 연결했다.
- 기존 프로젝트의 대본·스토리보드·고정 캐릭터와 검토 영상에 대해 정적 검증을 다시 수행했고 오류와 경고가 없었다.
- 선택 시점의 검토 대상은 `outputs/preview-compact-v4.mp4`였으며 원본 권리는 계속 `review_required`다.

## TTS·화면·배경음 동기화 개선

- 사용자의 검토 의견에 따라 검토본이라도 대사·음성·화면이 어긋나면 안 되는 결함으로 처리했다.
- 첫 0.6초는 대사 카드를 숨기고 제목과 `진짜인지 궁금하다면 말보다 행동을 보세요` 훅만 표시했다.
- 7개 Typecast WAV의 실제 앞·뒤 무음과 의미 있는 내부 멈춤을 측정해 11개 구절별 자막 구간을 `sync-plan.json`에 기록했다.
- 대사 카드는 해당 TTS 발화 구간에만 표시하고 구절 사이 무음에서는 숨겼다.
- 장면을 19개 모션 숏으로 나누고 구절 시작 또는 의미 있는 멈춤에 인서트·리액션·복귀 컷을 맞췄다.
- 외부 음원을 내려받지 않고 FFmpeg로 생성한 앰비언트 배경음을 추가하고 `rights-manifest.json`에 생성 파일과 해시를 기록했다.
- 새 검토본 `outputs/preview-synced-v5.mp4`를 생성하고 현재 선택 결과가 이 파일을 가리키도록 변경했다.
- 5개 대표 프레임에서 콜드 오픈 무대사, 첫 발화 자막, 무음 구간 자막 제거, 재훅, CTA를 확인했다.
- H.264/AAC, 720×1280, 30fps, 29.521초, 검은 프레임 없음, 프로젝트 검증 오류·경고 없음으로 확인했다.

## 신호 공개 연출 개선

- `신호 1~3`을 장면 시작부터 표시하던 방식은 답을 먼저 노출해 긴장을 낮추므로 제거했다.
- 평소 장면에서는 신호 라벨을 완전히 숨기고 관련 대사와 행동이 끝난 직후에만 약 1초 동안 공개한다.
- 각 신호는 `SIGNAL 01~03` 번호 원형과 핵심 문구가 3단계로 커지는 팝업으로 표시된다.
- 신호 공개 구간마다 별도 홀드 숏을 추가해 대사 화면과 결과 화면의 리듬을 분리했다.
- 장면 6을 0.3초 늘리고 장면 7을 0.3초 줄여 신호 3 공개 시간을 확보하면서 전체 길이 29.521초와 재훅·페이오프 위치 계약을 유지했다.
- 새 검토본은 `outputs/preview-signals-v6.mp4`이며 6개 대표 프레임에서 대사 전 신호 미노출, 세 신호의 대사 후 공개, CTA를 확인했다.
