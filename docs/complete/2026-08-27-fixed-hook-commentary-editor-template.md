# 고정 훅 해설 쇼츠 편집 템플릿 완료

- 작업일: 2026-08-27
- 위치: `projects/2026-08-27-fixed-hook-commentary-template`
- 범위: 참조 쇼츠에서 확인한 15개 컷의 리듬과 화면 계층을 독립형 브루·CapCut 편집 에셋으로 구성

## 완료 내용

- 1080×1920, 30fps, 1,275프레임(42.5초) 기준 15장면 타임라인을 구성했다.
- 고정 상단 2줄 제목, 하단 자막 상자, 장면 이미지 영역을 분리했다.
- `content.json`에서 제목·자막을 바꾸고 `assets/images/scene-01.png`부터 `scene-15.png`까지 교체할 수 있게 했다.
- 텍스트 합성 예시 `reference-preview.mp4`, 무문자 편집 베이스 `editable-base.mp4`, 레이아웃 없는 `clean-base.mp4`를 만들었다.
- 장면별 MP4, UTF-8 SRT 3종, CSV 타임라인, PNG 오버레이, JSON 매니페스트, 사용 안내와 ZIP 묶음을 만들었다.
- 참조 영상의 영상·음성·인물·밈·문구·로고·폰트는 포함하지 않고 새 플레이스홀더만 사용했다.
- `whiteboard-shorts` 플러그인 코드·설정·버전·설치 캐시는 이 작업에서 수정하지 않았다.

## 사용 경계

- 브루와 CapCut의 네이티브 프로젝트가 아닌 MP4·PNG·SRT 공통 파일 기반 일방향 패키지다.
- 편집기에서 바꾼 내용을 `content.json`으로 자동 역반영하지 않는다.
- CapCut 외부 SRT는 Desktop/Web 기준이며 모바일 직접 가져오기는 지원 범위에서 제외했다.
- 사용자가 교체하는 영상·이미지·음악은 게시 전 별도로 권리를 확인해야 한다.

## 검증

- 세 전체 MP4를 끝까지 디코딩해 오류가 없음을 확인했다.
- `editable-base.mp4`: H.264/AAC, 1080×1920, 30fps, 1,275 영상 프레임을 확인했다.
- `captions.srt`: 15개 구간을 확인했다.
- 오버레이 2종: 1080×1920 RGBA PNG를 확인했다.
- 일반 재생성 시 이미 존재하는 장면 PNG의 SHA-256이 유지되어 사용자 교체 이미지를 덮어쓰지 않음을 확인했다.
