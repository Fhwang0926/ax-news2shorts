# news2shorts Computer Use 뉴스 후보 탐색

## 완료 일자

- 2026-08-23

## 반영 범위

- 기사 후보나 추가 교차검증 기사를 찾을 때 NAVER API·웹 검색과 함께 읽기 전용 Computer Use 확인을 사용하도록 했다.
- 실시간 한국 뉴스 랜딩·검색·이슈 화면에서 헤드라인, 매체, 발행 시각, 원문 URL만 후보 식별 정보로 수집하도록 제한했다.
- Computer Use 화면은 후보 발견 수단일 뿐 사실, 인기, 국민 여론, 이미지 재사용 권리의 근거로 쓰지 않도록 했다.
- 최종 후보는 기존처럼 원문과 독립 출처로 교차검증하도록 유지했다.
- Computer Use가 없거나 화면 상태를 읽을 수 없으면 웹 검색으로 계속 진행하고 `Computer Use 미확인`을 결과에 표시하도록 했다.
- 로그인, 폼 제출, 다운로드, CAPTCHA, 유료벽과 접근 통제 우회는 금지했다.

## 변경 파일

- `plugins/news2shorts/skills/news2shorts/SKILL.md`
  - 후보 결과에 탐색 채널 범위를 표시하고 Computer Use 보조 탐색 절차와 검증 경계를 추가했다.
- `plugins/news2shorts/README.md`
  - 사용자용 후보 탐색 설명과 실패 시 대체 동작을 추가했다.
- `plugins/news2shorts/.codex-plugin/plugin.json`
  - 버전을 `0.25.0+codex.20260823003556`으로 올리고 실시간 브라우저 보조 탐색을 기능 설명에 반영했다.

## 수행하지 않은 작업

- 뉴스 후보를 실제로 새로 수집하거나 영상·음성을 생성하지 않았다.
- 외부 페이지 로그인, 제출, 다운로드 또는 게시를 수행하지 않았다.
- DB 작업과 프론트엔드 빌드는 대상이 아니므로 수행하지 않았다.
