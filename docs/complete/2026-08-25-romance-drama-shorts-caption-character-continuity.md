# 연애 드라마 Shorts 자막·캐릭터 연속성 개선 완료

## 요청

- 대본이 영상에서 더 깔끔하게 보이도록 자막 레이아웃을 정리한다.
- 지우와 서준이 이후 장면과 후속 영상에서도 같은 캐릭터로 이어지도록 고정 참조 에셋을 설정한다.

## 반영 내용

- 큰 검은 하단 띠와 별도 화자명 캡슐을 없애고, 실제 발화와 화자명을 함께 보여주는 얇은 반투명 하단 카드로 교체했다.
- 제목은 오프닝의 작은 상단 카드로, `신호` 문구는 대사와 분리된 작은 보조 라벨로 표시한다.
- 기존 Typecast Daeun·Piljae 음성과 20컷의 표정·휴대전화·손·찻잔 인서트 편집은 유지했다.
- 승인된 2인 캐스트 이미지를 바탕으로 지우·서준 각각의 정면·3/4·측면 동일 인물 참조 시트를 생성했다.
- `character-assets.json`에 캐릭터별 얼굴·나이대·헤어·의상·Typecast 음성 고정값과 참조 우선순위를 기록했다.
- 영상화 스킬은 앞으로 개별 캐릭터 참조 시트를 1순위, 승인된 2인 캐스트 참조를 2순위로 사용하고 참조 없는 반복 캐릭터 생성을 금지한다.
- 대사 카드는 고정 636px 폭 대신 실제 글자 폭에 맞춰 240~620px 사이에서 자동 조절하고, 화자명과 대사를 같은 줄에 배치했다.
- 한 줄 대사 카드 높이는 115px에서 70px로, 두 줄은 158px에서 106px로 줄였다.
- 생성된 각 장면을 개별 인물 참조와 승인된 2인 캐스트에 비교하고 얼굴·나이대·헤어·의상·음성이 다르면 다시 생성하도록 품질 게이트를 추가했다.
- 플러그인 버전을 `0.1.2+codex.20260825142309`로 올리고 Codex 설치 캐시에 재설치했다.

## 변경 파일

- `plugins/romance-drama-shorts/scripts/romance_drama_shorts.py`: 슬림 대사 카드·오프닝 제목·신호 라벨 렌더링.
- `plugins/romance-drama-shorts/skills/romance-video-producer/SKILL.md`: 개별 캐릭터 참조 에셋과 실제 발화 자막 규칙.
- `plugins/romance-drama-shorts/.codex-plugin/plugin.json`: 플러그인 버전 갱신.
- `projects/romance-drama-shorts/2026-08-24-us-yt-05-true-love-signals/character-assets.json`: 지우·서준 연속성 계약.
- 같은 프로젝트의 `cast.json`, `rights-manifest.json`, `project.json`: 참조 경로·생성 이력·최신 검토본 기록.
- 같은 프로젝트의 `assets/generated/characters/`: 지우·서준 개별 참조 시트.
- 같은 프로젝트의 `outputs/preview-compact-v4.mp4`, `compact-caption-report.json`: 축소 자막 검토 영상과 검수 결과.

## 검증

- 대표 6개 프레임에서 제목, 신호 라벨, 인서트, 긴 대사, 결론, CTA의 잘림과 얼굴 가림이 없는지 확인했다.
- 영상은 H.264/AAC, 720×1280, 30fps, 29.513초이며 오디오는 48kHz 스테레오다.
- 음량은 평균 -17.8dB, 최대 -2.7dB이고 검은 프레임이 검출되지 않았다.
- 프로젝트 검증은 오류와 경고 없이 통과했다.
- 영상화 Skill 검증, Python 구문 검사, 설치 캐시와 저장소 원본 해시 비교를 통과했다.

## 미완료 승인

- 원본 영상 권리는 `review_required` 상태라 이번 검토본에는 원본 컷을 사용하지 않았다.
- 권리, 합성 콘텐츠 표시, 게시 승인은 계속 미완료 상태이며 현재 결과물은 검토용이다.
- 프론트엔드 빌드와 DB 작업은 수행하지 않았다.
