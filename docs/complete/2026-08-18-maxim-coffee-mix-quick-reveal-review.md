# 맥심 커피믹스 경기일보 퀵리빌 검토본 완료

## 요청

- 경기일보 기사 `https://www.kyeonggi.com/article/20260817580218`을 바탕으로 퀵리빌 쇼츠를 영상까지 제작한다.
- 실제 제품 사진을 포함하되 재사용 권리를 확인하고, 결론과 출처를 화면에 명확히 표시한다.

## 완료 내용

- 기사에서 확인되는 굳음·변색 제보와 동서식품 답변을 사실표에 분리했다.
- 곰팡이·오염·위해성·동일 로트 확산 여부는 검사 전 미확인으로 유지했다.
- 재사용 허가를 확인할 수 없는 기사 사진은 제외하고, Pexels의 맥심 커피믹스 자료사진 1장을 사용했다.
- 설명용 생성 픽토그램 4장을 각각 다른 장면에 배치하고 720×1279로 최적화했다.
- 5장면 퀵리빌 구성에 훅, 중간 반전, 고정 결론 카드, 뉴스 출처, 장면별 줌 강조를 적용했다.
- 결론은 `정상 상태는 아니지만 원인은 미확인`과 `현품·포장지·사진 보관 후 제조사 또는 1399 접수`로 정리했다.
- macOS 키체인의 Typecast API 키 연결을 확인하고 Typecast `ssfm-v30`으로 다시 렌더링했다.
- 민감 뉴스용 자동 선택 결과로 `Seohyeon` 보이스(`tc_69f2e455ea79fd197aa0476f`)를 사용했다.
- 민감한 식품 안전 소재이므로 편집 승인 전 단계인 `preview.mp4`만 생성했다.
- YouTube 제목, 설명, 태그, 썸네일 장면, 재생목록, 시청자층, 공개 설정, 고정 댓글을 `publish.json`에 작성했다.

## 검증

- news2shorts 검증 통과: 오류 0건, 최종 규칙 미적용 검토본
- 영상: H.264, 720×1280, 30fps, 27.87초
- 오디오: AAC, 48kHz, 모노
- 마지막 프레임에서 결론 카드와 신고 안내가 잘리지 않고 유지되는 것을 시각 확인했다.
