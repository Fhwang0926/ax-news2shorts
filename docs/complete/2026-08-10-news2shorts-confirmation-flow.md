# 2026-08-10 news2shorts 사용자 확인 흐름 반영

## 작업 내용

- 뉴스 URL이나 단일 주제가 없을 때 후보를 최대 3개까지 수집·교차검증한 뒤 반드시 사용자가 주제를 선택하도록 변경했습니다.
- 기존의 비민감 뉴스 자동 선택 규칙을 제거했습니다.
- 주제 확인과 함께 조사, 대본, 이미지, 영상 중 결과물 범위를 확인하도록 추가했습니다.
- Codex가 `request_user_input`을 제공하는 환경에서는 기본 사용자 선택창으로 주제와 결과물 범위를 받도록 변경했습니다.
- 기본 선택창을 지원하지 않는 실행 환경에서는 `1번, 영상까지` 형태의 텍스트 질문으로 자동 대체하도록 했습니다.
- 기본 선택지 수 제한을 고려해 결과물 범위는 영상, 이미지, 텍스트로 먼저 묻고 텍스트 선택 시 대본 또는 조사로 한 번 더 구분합니다.
- 사용자가 이미 명시한 주제나 범위는 중복해서 묻지 않도록 했습니다.
- 이미지 범위는 프롬프트 제안이 아니라 실제 생성·수집 파일과 권리 기록까지 포함하도록 명시했습니다.
- 영상 범위는 출처, 대본, 이미지, 음성, 검토용 MP4, 렌더 보고서, 게시용 메타데이터까지 포함하도록 명시했습니다.
- 민감 뉴스, 권리 불명확 자료, 충돌하는 사실, 최종 렌더는 별도 검토 게이트를 유지했습니다.

## 대화 예시

후보 수집이 완료되면 플러그인은 추천 후보를 표시한 뒤 Codex 기본 선택창을 우선 사용합니다. 기본 선택창을 사용할 수 없는 경우에는 다음처럼 확인합니다.

```text
어떤 주제로 진행할까요?
결과물은 어디까지 만들까요? 조사 / 대본 / 이미지 / 영상

예: 1번, 영상까지
```
