# News2Shorts 자막·내용·이미지 정합성 개선

## 작업 내용

- `interest-rate-again` 검토본의 여섯 장면을 내레이션과 화면 문구가 같은 사실을 말하도록 다시 구성했다.
- 중간 장면에 기준금리 2.75%에서 3.00%로 오른 흐름을 나타내는 상승 막대·화살표 그래픽을 적용했다.
- 전체 차주 1조8천억 원 추산 대신, 대출 잔액 1억 원에 0.25%포인트가 그대로 반영된다는 단순 가정으로 연 25만 원·월 약 2만800원 증가액을 제시했다.
- 마지막 화면을 `곧 오릅니다? / 은행이자 · 대출이자 / 1억 대출 · 연 25만원↑`로 바꾸고, 내레이션에는 실제 반영 폭과 시점이 약정 금리·재산정일에 따라 다르다는 조건을 유지했다.
- 제목과 설명은 같은 문장을 반복하지 않도록 각각 질문과 계산 결과 역할로 분리했다.

## 보존 경계

- 기존 수집 이미지와 권리 기록은 삭제하지 않고, 개선본에서 사용하지 않는 자료는 보조 후보로만 보존했다.
- 외부 업로드와 공개는 수행하지 않으며, 금융 민감 주제의 편집 승인 전까지 검토본으로만 유지한다.

## 검증 결과

- 프로젝트 검토 기준은 오류 0건, 경고 0건으로 통과했다.
- Typecast `Seohyeon` 음성으로 검토본을 재렌더했다.
- 결과 영상은 29.211초, 720×1280, 30fps, H.264/AAC이며 영상·음성 디코딩을 확인했다.
- 중간 상승 그래픽, 1억 원 계산 사진, 마지막 결론 카드의 실제 프레임을 확인했다.
- 최종 공개 기준은 편집 승인(`editorial_reviewed`) 전이므로 의도대로 차단된다.
