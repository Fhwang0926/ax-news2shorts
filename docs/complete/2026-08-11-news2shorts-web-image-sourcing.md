# news2shorts 웹 이미지 수집 반영 완료

## 완료 내용

- 이미지·영상 범위에서 스토리보드별 웹 이미지 검색을 기본 단계로 추가했다.
- 공식 자료, 퍼블릭 도메인, Creative Commons 원본 페이지를 우선 확인하도록 했다.
- 검색 결과 썸네일이나 기사 이미지를 다운로드 가능하다는 이유만으로 사용하지 않도록 명시했다.
- 선택한 이미지는 `assets/collected/`에 저장하고 로컬 파일을 다시 시각 확인하도록 했다.
- 사용할 수 있는 웹 자산이 없으면 검색 판단을 기록한 뒤 생성 이미지로 보완하도록 했다.
- `rights-manifest.json`에 `searches` 배열을 추가해 검색어, 장면, 시점, 결과, 선택 파일, 판단 메모를 기록한다.
- 수집 이미지의 원본 URL, 제작자·게시자, 라이선스, 표시 문구, 수집 시각, `source_method`를 검증한다.
- Google·NAVER·Bing 검색 결과 URL을 원본 출처로 기록하면 검증에서 거부한다.
- 기존 프로젝트는 설정이 없으면 호환되고, 새 프로젝트는 웹 검색과 생성 폴백을 기본 활성화한다.
