# 연애 드라마 Shorts 박스 레이아웃·립싱크 계약 반영 완료

## 요청

- 참고 화면처럼 세로 캔버스의 위·아래에 여백을 둔다.
- 고정 캐릭터의 입 움직임을 Typecast 음성과 맞출 수 있는지 검토한 내용을 영상화 플러그인에 반영한다.

## 반영 내용

- 창작 검토본을 720×1280 오프화이트 캔버스, 상단 제목, 중앙 640×800 둥근 영상창, 하단 여백으로 구성했다.
- 정확한 제목 본문은 검정, `신호 3가지`는 노란색으로 분리해 참고 화면의 제목 계층을 반영했다.
- 대사 카드, 훅, 신호 공개, CTA를 중앙 영상창 내부에 유지하고 플랫폼의 계정·음악·반응 UI는 모사하지 않았다.
- 기존 Typecast WAV의 발화 구간 자막, 대사 비트 화면 전환, 신호 후공개, 생성 BGM은 그대로 유지했다.
- 권리 상태가 확인된 프로젝트 로컬 립싱크 MP4를 숏 단위 `lip_sync_video`로 받아 기존 Typecast 음성과 합성하는 입력 계약을 추가했다.
- Runway 연결을 승인받았지만 연결된 작업공간에 영상 모델이 없어 영상 생성은 실행하지 않았다.
- OpenAI 이미지 편집으로 지우·서준의 동일 장면에서 입만 살짝 열린 보조 포즈를 만든 뒤, 로컬에서 Typecast WAV 세기에 맞춰 작은 입 영역만 혼합했다.
- 장면 1의 지우 대사 숏 1개와 장면 2의 서준 대사 숏 2개에 미세 입 움직임을 적용했다. 휴대전화 인서트, 신호 공개, 투숏·리액션에는 강제하지 않았다.
- 이 동작은 음성 세기 기반 2포즈 파일럿이며 음소 단위 정밀 립싱크로 표시하지 않는다.

- `plugins/romance-drama-shorts/skills/romance-video-producer/SKILL.md`: 기본 박스 레이아웃과 립싱크 적용·외부 전송 규칙.
- `plugins/romance-drama-shorts/README.md`: 사용 방법과 립싱크 로컬 클립 계약.
- `plugins/romance-drama-shorts/.codex-plugin/plugin.json`: `0.1.7+codex.20260825215833` 버전 갱신.
- 프로젝트 `sync-plan.json`, `lip-sync-pilot.json`, `project.json`: v7 출력, 파일럿 대상, 품질 게이트와 상태 기록.
- 프로젝트 `assets/generated/lip-sync/`: 지우·서준 발화 입 포즈와 음성 세기 기반 3개 대사 숏.
- 프로젝트 `outputs/preview-boxed-lipsync-v9.mp4`, `boxed-lipsync-v9-report.json`: 최종 검토 영상과 검수 결과.

## 검증

- H.264/AAC, 720×1280, 30fps, 29.521초, 48kHz 스테레오로 확인했다.
- 오프닝, 첫 대사, 신호 1, 리훅, 신호 3, CTA 대표 프레임에서 제목·영상창·대사·신호·CTA 잘림이 없는지 확인했다.
- 전체 영상 디코딩과 검은 프레임 검사를 통과했다.
- 프로젝트 검증은 오류와 경고 없이 통과했다.
- 영상화 Skill 검증, Python 구문 검사, `git diff --check`, 립싱크 로컬 클립 합성 경로의 0.5초 스모크 검증을 통과했다.
- 플러그인 설치 캐시를 `0.1.7+codex.20260825215833`으로 갱신했다.

## 남은 경계

- 현재 v9의 입 움직임은 장면 1·2의 3개 대사 숏에만 적용됐다.
- 음소 단위 정밀 립싱크가 필요하면 영상 모델이 사용 가능한 상업 이용 제공자 연결과 별도 파일럿 검수가 필요하다.
- 권리, 합성 콘텐츠 표시, 게시 승인은 계속 미완료이며 결과물은 로컬 검토용이다.
- DB 작업과 프론트엔드 빌드는 수행하지 않았다.
