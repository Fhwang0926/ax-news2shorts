# GS25·쿠팡 개인정보 유출 비교 검토 영상 완료

## 작업 범위

- 사용자 지정 주제 `GS편의점, 너도 쿠팡 닮아가냐?`로 news2shorts quick-reveal 프로젝트 생성
- 개인정보보호위원회 공식 처분문과 독립 보도를 이용해 GS25, GS SHOP, 쿠팡 수치와 침해 원인 구분
- 대본, 팩트시트, 6장면 스토리보드, 권리 기록, 썸네일, 검토용 MP4, CapCut/Vrew 편집 패키지, YouTube 업로드 정보 생성

## 결과 위치

- 프로젝트: `outputs/2026-08-31/gs편의점-너도-쿠팡-닮아가냐/`
- 검토 영상: `preview.mp4`
- 별도 썸네일: `thumbnail.jpg`
- 편집 패키지: `edit-package/preview/`

## 핵심 사실 구분

- GS25 개인정보 유출 대상: 79,128명
- GS SHOP 포함 GS리테일 전체: 1,660,153명
- 쿠팡 공식 확인 유출 대상: 약 3,755만명
- GS리테일은 크리덴셜 스터핑과 이상징후 탐지·연계 대응 실패, 쿠팡은 인증 서명키와 접근통제 관리 부실로 침해 원인이 다름

## 시각 자료와 권리

- 사용자 피드백에 따라 생성 설명 픽토그램 2개를 영상과 썸네일에서 제외함
- 현재 장면은 실제 GS25 점포 2장, 실제 쿠팡 배송물 2장, 개인정보위 실제 처분문 2쪽으로 구성되어 사용 시각 자료 100%가 비합성 자료임
- 장면 3은 개인정보위 처분문 2쪽의 GS25 79,128명, 동일 IP 327개, 이상징후 탐지 실패, 인지 뒤 추가 유출 문단을 사용함
- 장면 6은 개인정보위 처분문 1쪽의 과징금 128억3,600만원과 시정명령 요약을 사용함
- 기사 사진과 검색 썸네일은 사용하지 않음
- GS25 워터마크 사진과 차량 번호가 보이는 쿠팡 사진은 검수 후 제외
- 사용 사진은 Wikimedia Commons의 CC0 또는 CC BY-SA 4.0 자료이며, 최종 공개 전 CC BY-SA 표시·동일조건 의무를 사용자와 최종 확인해야 함
- 개인정보위 문서 이미지의 외부 재사용 조건은 별도 표시가 확인되지 않아 `review_required`, `local_review_only`로 유지함

## 검증

- draft validation: 오류 없음
- 영상: 720×1280, H.264/AAC, 30fps, 28.07초
- 첫 답변: 2.666초, 기준 8초 이내 통과
- truth guard: 2.666초, 기준 4초 이내 통과
- 중간 CTA: scene-03 뒤 12.685초, 본문 비율 46.56%
- 최종 검증은 `editorial_reviewed`, `rights_reviewed` 승인 전이라 의도대로 차단됨
- 프론트엔드 빌드와 DB 작업은 수행하지 않음

## 음성 제한

- Typecast 키체인 접근은 정상 확인됨
- 최초 Typecast WAV 외곽 무음 정리 중 FFmpeg가 비정상적으로 큰 임시 WAV를 생성하려 해 렌더가 실패했으며 임시 파일은 자동 정리됨
- `plugins/news2shorts/scripts/news2shorts.py`의 Typecast 외곽 무음 정리에 원본 WAV 길이 검증, FFmpeg 입력·출력 길이 상한, 결과 길이 검증을 추가함
- 캐시버스터를 `0.36.5+codex.20260831051136`으로 갱신하고 `news2shorts@news2shorts-local`을 재설치함
- 소스와 새 설치 캐시의 SHA-256 일치 및 플러그인 검증 통과
- 새 캐시에서 Typecast 자동 보이스 `Seohyeon`으로 검토 영상을 정상 재렌더함
- 실제 이미지 Typecast 검토 영상은 25.60초이며 첫 답변·truth guard 2.423초, 중간 CTA 11.273초, payoff 6.6초로 최종 길이 상한 안에 있음

## 강조점 수정

- 기존 결론의 비밀번호 분리·2차 인증 이용자 행동 강조를 제거함
- 최종 메시지를 `공격 원인은 다름 → GS25 유출 인지 뒤에도 GS SHOP 공격을 놓침 → 고객정보 보호 실패는 닮음`으로 고정함
- 업로드 설명도 이용자 행동보다 기업의 탐지·접근통제·사고대응 실패를 중심으로 수정함
