# 2026 추석 명절지원금 팩트스택 완료

## 요청

- 네이버 프리미엄콘텐츠의 `2026 추석 명절지원금 지급대상 신청방법 안내`를 바탕으로 팩트스택 쇼츠를 영상까지 제작한다.
- Typecast 음성을 사용하고, 결론·출처·업로드 정보를 최종 결과에 포함한다.

## 완료 내용

- 원문 공개 구간과 복지로의 강서구·서대문구 사업, 보건복지부 기준을 교차검증했다.
- 전국 공통 지급이 아니라 주소지별 별도 복지사업이라는 결론으로 정리했다.
- 강서구 생계·의료급여 수급 가구 2만 원, 서대문구 일정 저소득 한부모가족 5만 원 사례를 대조했다.
- 화면 문구를 명사형으로 제한하고 마지막 장면에 `주소지별 별도 사업` 결론 카드를 배치했다.
- 서로 다른 Pexels 자료사진 2장과 글자 없는 평면 픽토그램 5장을 사용했다.
- 기사 대표 이미지와 한국 원화 사진은 별도의 안전한 재사용 근거를 확보하지 못해 사용하지 않았다.
- 생성 이미지는 모두 720×1279로 최적화하고 권리·생성·육안 검수 기록을 남겼다.
- 키체인의 Typecast API 키를 확인하고 `Moonjung` 보이스로 최종 음성을 생성했다.
- 제목, 링크 없는 설명, 태그, 썸네일 시점, 재생목록, 시청자층, 공개 설정, 고정 댓글을 작성했다.
