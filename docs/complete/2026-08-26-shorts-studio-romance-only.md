# Shorts Studio 로맨스 전용 정리

## 완료 내용

- `Shorts Studio`의 지원 범위를 승인된 2인 로맨스 드라마 쇼츠 제작으로 한정했다.
- `story` 명령과 원본 영상 기반 이야기 입력 처리 경로를 제거했다.
- `shorts-story-producer` 스킬과 관련 기본 프롬프트를 제거했다.
- 플러그인 설명, 루트 README, 사용 문서와 테스트 fixture를 `romance` 단일 모드 기준으로 정리했다.
- 기존 프로젝트와 과거 완료 문서는 기록 보존을 위해 수정하거나 삭제하지 않았다.

## 유지한 경계

- 승인 순서는 `assets → content → publish`를 유지한다.
- 합성 장면 표시 검토, 게시 가능한 권리와 Typecast 음성 조건을 유지한다.
- 검토되지 않은 립싱크, 공개 URL 취득과 YouTube 직접 업로드는 지원하지 않는다.

## 확인 안내

- 작업 지침에 따라 빌드와 자동 테스트는 실행하지 않았다.
- 필요하면 `romance` 전체 fixture 렌더와 제거된 `story`, `price` 명령 차단을 별도로 확인해야 한다.

프론트엔드, DB, 외부 API와 기존 영상 산출물은 변경하지 않았다.
