## 사진 내용·품질 및 공개 인물 화풍 검증

- 새 프로젝트 기본값에 `visual_validation_mode: evidence-first`를 추가했다. 기존 프로젝트에 이 필드가 없으면 레거시 규칙을 유지해 현재 초안을 소급 파손하지 않는다.
- 각 장면이 `fact_ids`와 `visual_requirement`를 기록하도록 했다. 구체 사건은 `direct_incident`, 공개 인물 소개는 `direct_subject`, 설명 장면은 `contextual`, 의도적인 상징 화면만 `symbolic_allowed`를 사용한다.
- 수집 후 사진을 직접 확인하고 기록하는 `review-asset` 명령을 추가했다. 내용·품질 승인, 현재 원본 SHA-256, 연결 fact ID, 실제 보이는 내용, 핵심 피사체 식별, 9:16 크롭 안전을 모두 확인해야 CapCut 사용 검증을 통과한다.
- 실제 저해상도 사건 자료는 합성 HD 이미지로 바꾸지 않고 경고와 사람 검수로 유지한다. 합성 이미지는 사건·공식·출처 캡처 역할을 주장할 수 없다.
- 공개 인물 신원 사진은 `source_photo` 원본으로 보존하고 화면에서 직접 사용하지 않는다. 실제 원본에서 한 번만 파생된 text-free `editorial_animation`, `portrait_style: editorial-animation` 결과만 `direct_subject` 화면에 사용할 수 있다.
- 공개 인물 파생본은 신원·의상·사실 맥락 보존 승인이 모두 필요하다. 실제 사건 영상·공식 페이지·기사·방송 캡처는 공개 인물이 보여도 원본 텍스트·출처·워터마크를 유지한 실제 자료로 사용할 수 있다.
